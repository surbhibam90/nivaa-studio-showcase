# NIVAA Studio Showcase

I'm making website for interior designer and i'm attaching mockups and hero section video.

Build a premium, highly polished, minimal interior-design studio website called NIVAA — Spaces That Feel Like You.

I am providing visual reference mockups for the Home, Services and Portfolio pages, along with a short cinematic living-room video for the Home hero section.

IMPORTANT: Treat the provided mockups as the primary visual direction. Do NOT redesign them into a generic template. Recreate their visual language, composition, spacing, typography hierarchy, organic shapes, image treatments and overall premium feel as closely as possible while making the website responsive and production-quality.

WEBSITE GOAL

The website should feel like a high-end interior design studio website — editorial, architectural, calm, sophisticated and memorable.

It should NOT feel like:

a generic corporate website

a template

a standard Bootstrap website

a basic portfolio grid

an overly animated flashy website

Think:
luxury interior magazine + modern architecture studio + cinematic digital experience.

The experience should be beautiful even before the user reads the content.

DESIGN DIRECTION

Use a warm, sophisticated palette inspired by the mockups:

warm ivory / off-white

cream

sand

beige

taupe

muted olive / deep botanical green

warm brown

charcoal for typography

Avoid bright colors.

Typography should combine:

an elegant editorial serif for major headlines

a clean modern sans-serif for navigation, body copy and labels

The typography should have generous spacing and strong hierarchy.

Use large editorial headlines with occasional italic serif emphasis.

Example:

Beautiful
Spaces
Brighter Lives

Do not use excessive bold text.

MOST IMPORTANT VISUAL PRINCIPLE

Do NOT separate every section with straight horizontal borders.

The entire website should feel like one continuous flowing composition.

Use:

large organic curves

asymmetric section transitions

soft wave-like boundaries

oversized rounded image containers

blob-like masks

arch shapes

overlapping sections

images partially crossing section boundaries

curved background transitions

subtle layering

One section should visually flow into the next.

The transition between sections should feel designed, not like:

SECTION

SECTION

SECTION

Instead, use shapes and curves to create a continuous visual journey.

ANIMATION PHILOSOPHY

Animation should feel luxury and cinematic, not flashy.

Use subtle:

fade + upward reveal

image parallax

smooth scale

masked image reveals

text stagger

organic shape movement

gentle hover transformations

smooth page transitions

Animations should generally be slow and elegant.

Avoid:

excessive bouncing

aggressive zooms

spinning UI

unnecessary particle effects

excessive scroll-jacking

animation on every element

Use animation to support the design.

Respect prefers-reduced-motion.
